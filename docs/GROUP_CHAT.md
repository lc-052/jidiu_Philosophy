# 圆桌群聊与用户形象

## 本轮变化

- 22 位思想家使用原创 Canvas 抽象肖像，以发型、胡须、眼镜、配色区分。选人卡片、探索详情、群成员与消息头像统一；不使用真人照片或未经授权图片。头像是产品插画，不是对历史外貌的考证。
- “我的 → 编辑形象”和圆桌准备页“编辑形象”进入用户界面。可设置最多 20 字昵称，选择小芽、月亮、小猫、云朵、太阳、星球六款原创头像，支持保存与重建恢复。无需账号。
- 会议开始后进入群聊布局：顶部话题与成员，哲学家在左、用户在右，发言包含昵称与头像，回应目标单独标注；底部固定多行输入框与发送按钮。新消息自动滚动到底部。
- 用户发言保存当时昵称，修改昵称后旧发言不改名；头像跟随当前本机形象。昵称随当前讨论上下文发送模型，头像图片不发送。
- 讨论仍是 AI 思想推演，不是真实哲学家或其他在线用户群聊。未配置模型时明确显示演示，演示只保存用户发言。API Key 直连、历史、收藏与重新开桌继续可用。

## 实际验证

完整产品测试增加昵称编辑、头像选择、保存后 Activity 重建恢复、发言昵称持久化与用户消息展示。直连测试使用底部发送控件验证 HTTP 请求、追问与上下文。结果与 APK 信息见 [VALIDATION.md](VALIDATION.md)。
