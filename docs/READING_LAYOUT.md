# 圆桌阅读排版（1.0.5）

- 发言正文为 15sp，行高 25sp，段落之间 12dp；保留系统字体缩放。
- 哲学家的姓名与 28dp 头像在正文上方，消息占满可用宽度。浅色使用白色气泡和细边框，深色跟随主题，减少长文的左侧缩进。
- 已有长发言按照完整句子分段，仅改变显示，不改写原文、不修改数据库或传输内容，不截断发言。已有换行保留；没有标点的长句不硬切。
- 手机直连与可选 Backend 的生成提示都要求先表达立场，再用两至三个短段落解释。模型是否遵守仍取决于模型；客户端提供历史消息的分段显示。
- 入座成员改成横向小头像与名称，长昵称单行省略，避免挤压和溢出。用户形象编辑入口保留。
- 输入和发送合为一行，移除重复说明。发送按钮保留 48dp 触控范围和中文无障碍描述，长输入最多显示四行并可滚动。
- 新打开的讨论从第一条发言开始；追加讨论滚动到新增内容的开始，避免跳过新发言。页面重建沿用列表和会话状态。

验证：分段的原文完整性、原有段落、无标点长句和空内容均有单元测试；小屏 320dp、180% 字体、深色长文通过设备测试；既有完整产品流程继续回归。

本次调整没有给旧回复补写摘要或删除内容。实际手机阅读效果仍会受到字体、系统字号和屏幕宽度影响。
