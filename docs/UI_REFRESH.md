# UI 整理记录

日期：2026-10-07。

## 页面组织

| 板块 | 调整后的重点 |
| --- | --- |
| 今天 | 问候与角色合并为紧凑头部；今日问题是主视觉；选项同等权重；换题为次级操作 |
| 探索 | 横向内容分类；问题主题筛选；当前分类搜索与清空；结果数量；整张卡片可打开；关系地图位于人物／流派分类 |
| 我的 | 统计摘要；集中历史、收藏、思想轨迹三个入口；随后展示思想画像；算法说明按需展开 |
| 圆桌会议 | 话题 → 邀请 → 开始会议；横向演示话题与人物卡片；简洁演示提示；讨论页突出本桌话题、发言人和用户追问 |
| 结果 | 先突出本次选择，再显示原问题；倾向、背景、观点与 Reflection 按段落组织 |
| 收藏 | 全部、问题、哲学家、流派、圆桌筛选，分类空状态 |
| 历史 | 日期、问题、当时选择和留言使用不同文本层级 |
| 设置 | 外观与节奏、数据与隐私两组；删除仍二次确认 |

## 视觉与可用性

- 定义统一字号、行高、字重和圆角；主标题 28sp、分区标题 20sp、正文 16sp / 27sp。
- 新增 PageHeading、SectionHeading、NavigationRow 公共组件；导航入口提供图标、解释与方向提示。
- 问题选项使用柔和背景、轻边框与至少 56dp 触控高度，选中时仍有明确勾选。
- 列表简介适度截断，详情页保留完整内容；组件避免固定文本高度。
- 底部导航的当前页同时改变图标／文字颜色与字重；头像、吉祥物沿用 Canvas，无外部素材。
- 保留深色主题、字体缩放、键盘避让、状态恢复和滚动列表的稳定 key。
- 数据模型、保存流程和画像算法沿用原实现，不执行用户数据删除或数据库重置。自动化测试仅重置专用模拟器中的测试记录。
